# Prompt 09 — Private Beta Release

```text
Continue from the persistent Beta Sports MVP context and completed hardening phase. Prepare a private beta release only.

Deliver:
1. Production deployment configuration with separate staging/production environments and no leaked secrets.
2. Google OAuth production redirect configuration checklist.
3. PWA manifest, icons/placeholders, install guidance, offline-safe read experience, and clear behavior for queued/failed writes.
4. Seeded demo group and a controlled beta-invite workflow.
5. In-app feedback link/form that does not expose private data to other members.
6. Lightweight operational dashboard: sign-in errors, failed writes, job failures, and anonymized product events.
7. Release checklist, rollback checklist, support playbook, and a 30-day beta feedback plan.

Do not publish to app stores, create paid subscriptions, send invitations externally, or process user payments unless specifically authorized. Report launch blockers separately from non-blocking polish.
```
